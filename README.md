This project was developed within the course Systems Analysis and Design and represents a complete elaboration of the application “Market Discount Tracker”. The repository covers all essential phases of system analysis and design, starting from the initial data, through structuring and modeling, to integration, visualization, and documentation. The raw data is stored in a dedicated directory for processing and is modeled both in a relational database with a normalized structure and in JSON format, which enables exchange and testing with external applications. For analytical requirements, a data warehouse is utilized to provide historical views and support business analysis, while automated data processing and transformation are implemented through configurations created in Apache NiFi. The results of the system are presented in Power BI through interactive reports and visualizations. The system is further modeled using UML diagrams, prepared in both Macedonian and English, in order to represent the functional and structural architecture of the solution. The documentation includes the formally described requirements as well as a detailed text about the selected application, which serves as the foundation for analysis, design, and further implementation. With this organization, the project ensures full coverage of all phases of information system development, starting from requirements definition, through conceptual and logical design, to visual presentation and practical application.
